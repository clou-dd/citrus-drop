**Pre-release · 개발 중인 테스트 버전입니다.**

Windows 10/11 64비트에서 아래 Assets의 **`CitrusDrop.exe`**를 내려받아 실행하세요. Python 설치나 `_internal` 폴더는 필요하지 않습니다.

### 주요 기능

- 파일 드래그 중 Shift를 누르면 표시되는 원형 변환 메뉴
- 이미지 형식 변환, 이미지 → PDF, PDF → PNG/JPG/TXT
- FFmpeg 연결을 통한 영상·음성 변환, ZIP 압축·경로 복사
- 단일 EXE, Pretendard 폰트, 앱 정보·라이선스 안내

### 이번 버전

- 상단 버튼을 `앱 정보`로 정리했습니다.
- 사용 안내 영상과 간결한 다운로드·사용 안내를 제공합니다.
- GitHub Releases에서 프리릴리즈 EXE를 배포합니다.

영상·음성 변환용 FFmpeg는 포함하지 않으며 앱에서 별도로 선택합니다. PDF 문자 추출은 OCR을 지원하지 않습니다.
