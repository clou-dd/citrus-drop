# Citrus Drop 사용 안내 영상

- 앱 버전: v0.3.3
- 원본: [citrus-drop-guide.mp4](citrus-drop-guide.mp4), 1920×1080, 30fps, 24초, H.264, 오디오 없음
- README 미리보기: [citrus-drop-guide.gif](citrus-drop-guide.gif), 960×540, 10fps, 24초, 반복 재생
- 구성: PDF → JPG → 생성 폴더·JPG 열기 / PNG → PDF → 결과 PDF 열기
- Windows 배경·아이콘·탐색기·뷰어·커서 동작은 사용 안내를 위해 구성한 합성 화면입니다. Windows 실기기 화면 녹화는 아닙니다.
- 원형 메뉴는 실제 Citrus Drop Qt 위젯을 사용했습니다. 실제 드롭 이벤트로 PDF·이미지 변환을 실행했으며, 성공 상태·원본 파일 보존·생성된 JPG 디코딩·PDF 페이지 렌더링을 확인했습니다.
- 원본 영상의 전체 디코딩에 오류가 없으며, 720프레임·24초·비디오 스트림 하나·오디오 없음인 것을 확인했습니다.
- 파란 바탕화면은 직접 그린 Windows 스타일 벡터 배경입니다. 참고 릴스의 영상·음악·이미지는 포함하지 않았습니다.
