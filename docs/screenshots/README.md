# 실제 앱 화면 캡처

- 앱 버전: v0.3.2
- 캡처 환경: Linux / Python 3.12 / PySide6 6.8.3 / Qt offscreen / Pretendard v1.3.9
- 캡처 방식: 실행 중인 실제 QWidget의 `grab()` 결과를 PNG로 저장했습니다. 디자인 목업이나 합성 화면이 아닙니다.
- 샘플 파일: 저장소의 프로젝트 로고 PNG를 임시 폴더에 두 번 복사했습니다. 개인 파일은 사용하지 않습니다.
- 원형 메뉴: 로컬 파일 URL을 담은 Qt 드래그 진입·드롭 이벤트를 실제 위젯에 전달했습니다. Windows 탐색기의 OLE 드래그나 전역 Shift 감지를 시연하는 캡처는 아닙니다.
- 완료 화면: 원형 메뉴의 PDF 만들기를 드롭 이벤트로 실행했습니다. 실제 변환 작업 스레드가 끝난 뒤 성공 상태, 생성된 PDF의 2페이지 구성과 첫 페이지 렌더링을 확인하고 캡처했습니다. 경로·시간은 해당 실행의 임시 결과입니다.

## 재현

프로젝트 의존성과 폰트를 준비한 뒤 저장소 루트에서 실행합니다.

```shell
python tools/fetch_fonts.py
python tools/capture_screenshots.py
```

`QT_QPA_PLATFORM`을 지정하지 않으면 offscreen을 사용합니다. 화면 파일은 이 폴더에 저장됩니다. 실제 앱의 UI와 변환 경로를 사용하므로 앱이 변경되면 캡처도 다시 생성해 주세요.
