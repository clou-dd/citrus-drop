Optional PDF-to-image/text engine:
Extract the complete Poppler Windows distribution here, keeping DLLs,
Library/bin, Library/share, and the other supplied folders together.
Recognized locations for pdftoppm.exe:
  tools/poppler/Library/bin/pdftoppm.exe
  tools/poppler/bin/pdftoppm.exe
  tools/poppler/pdftoppm.exe
Or select your existing pdftoppm.exe using the app's PDF engine setting.
pdftotext.exe in the same directory enables UTF-8 text extraction (no OCR).
Windows package project: https://github.com/oschwartz10612/poppler-windows
Upstream: https://poppler.freedesktop.org/
No Poppler executables, DLLs, fonts, or data files are bundled here.
Image-to-PDF creation does not require Poppler.
